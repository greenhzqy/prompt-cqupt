# prompt-cqupt · 抖音口播文案提示词库（重邮学长）

> 一个**纯提示词（Prompt）分享仓库**：把「重邮学长」账号在用的抖音口播文案生成提示词沉淀成 Markdown 文件，复制就能用，换个主题就能接着复用。

---

## 这个仓库是干什么的

一句话：**这里不放代码，只放提示词。**

仓库里目前只有一个 Markdown 文件，内容是同一套「抖音口播文案生成提示词」的两个版本（通用版 + 优化版）。它的用途很具体——当你要拍一条抖音口播视频，主题定了（比如"高考完暑假必做的三件事"），但每次从零憋文案都很痛苦时，把这份提示词整段丢给 AI，末尾补一句主题，就能拿到一版符合博主本人人设、语气、结构和禁忌的初稿。

换句话说，它解决的不是"能不能写"，而是**"写出来像不像这个账号说的"**：人设固定、语气固定、结构固定、禁忌固定，AI 输出的稳定性来自这些约束。

需要说明的几点：

- **这不是代码项目**：没有依赖、没有构建、没有部署，也没有任何脚本。克隆下来能做的唯一一件事，就是打开文件、复制、粘贴。
- **提示词绑定了一个具体的账号人设**：作者是重庆邮电大学在读学生，账号名「绿色的氢原子」，提示词里的"重邮大一学长"身份、亲身经历库都是围绕这个账号写的。想用在别的账号上，需要先替换人设与经历部分（见下文「使用注意事项」）。
- **内容来自真实使用**：文件里出现的经历（转专业、剪辑接单、128G 手机清内存、600 元二手平板等）都是作者本人写进提示词的素材，不是示例占位符。

## 提示词一：通用版（文件上半部分）

标题为《抖音口播文案通用生成提示词（直接复用，换主题即可）》，是一份**扁平结构的完整提示词**，直接整段可用。原文包含六个要素：

| 要素 | 原文要点 |
| --- | --- |
| **人设** | 重庆邮电大学大一在读学长，账号「绿色的氢原子」；真实接地气的直系学长身份；有转专业、靠剪辑接单赚生活费、用 AI 做内容、手工折纸／焊电路板的亲身经历 |
| **语气定位** | 像和学弟学妹面对面唠嗑，平等交流，无说教感，不端着，有过来人真诚感 |
| **风格** | 短句快节奏，适配怼脸口播；**单句不超过 15 字**；口语化 |
| **用词禁忌** | 不用书面语、鸡汤文、烂俗网络梗；不用「宝子」类称呼，统一用「学弟学妹」「大家」 |
| **内容要求** | ① 紧扣高考志愿填报、重邮转专业、大一新生攻略、暑假自我提升等热点，戳高三毕业生／重邮准新生的痛点；② 尽量融入个人真实经历佐证观点（如"我当年暑假剪游戏视频被博主看中""我转专业踩过的坑"）；③ 干货直接给结论，信息密度高，无废话 |
| **结构** | 开头 3 秒强钩子（共鸣问句／痛点直击）→ 中间分点输出，每点讲清"是什么 + 有什么用／怎么做"→ 结尾引导互动（如"有问题评论区说，学长挨个回"） |
| **总禁忌** | 避免说教语气、空泛鸡汤、夸大效果；不制造焦虑；保持真诚实用的学长调性 |

**它的使用方式很特别**：提示词里没有 `{主题}`、`{{topic}}` 之类的占位符，而是要求你**在末尾手动补一句**——

> 使用方法：每次生成文案时，在结尾补上一句「本次主题：XXX」即可，比如「本次主题：高考完暑假必做的三件事」。

文件末尾还自带一条注记：`（注：部分内容可能由 AI 生成）`。

## 提示词二：优化版（文件下半部分）

标题为《账号口播文案生成提示词（优化版）》，是通用版在同一文件里的**结构化升级版**，按「一、基础人设 → 二、表达风格 → 三、内容创作要求 → 四、固定结构 → 五、禁忌要求」五个章节组织。相比上半部分，它主要做了四件事：

### 1. 建了一个可调用的「亲身经历库」

明确要求"创作时优先融入佐证观点"，并把素材按三类列好：

| 类别 | 已入库的经历 |
| --- | --- |
| **学业类** | 有转专业亲身经历，踩过转专业的坑；有焊电路板、手工折纸的实操经历 |
| **创收类** | 靠剪辑接单赚生活费，暑假剪游戏视频被博主看中；运营自媒体账号，用 AI 写文案提升效率 |
| **生活消费类** | **手机**：大一上用 128G 手机踩过内存坑，天天清内存、无法开展账号拍摄，换大内存后体验改善<br>**电脑**：自用游戏本，去年入手价格合适；了解今年内存、存储涨价、游戏本普遍涨价的行情<br>**平板**：自用 600 元二手平板，靠自己接单赚钱购入；有图书馆无纸化学习、刷网课、看电子书的真实使用体验 |

### 2. 把主题范围从 4 类扩到 5 类

核心主题范围变为：高考志愿填报、重邮转专业攻略、大一新生入学攻略、暑假自我提升、**大学电子产品／好物选购**。

### 3. 新增「电子产品类固定核心观点」

要求创作电子产品类内容时必须覆盖以下结论，并且**客观中立、兼顾优缺点、不盲目种草、不制造焦虑**，优先传递"按需选购、性价比优先"：

- **手机**：优先选 512G 大内存，小内存会严重影响学习、创作体验；
- **笔记本**：不盲目冲游戏本，按专业需求和使用场景选；今年游戏本涨价明显，非必要不花冤枉钱；
- **平板**：非大学必备品；优点是便携、适合刷网课／无纸化学习、看电子书省书本费，缺点是"不拿来学习极易吃灰"；预算有限推荐入手二手款。

### 4. 收紧禁忌

在通用版的基础上，额外加上**不硬推产品、不推荐具体品牌型号**（避免变成广告口播）。

### 创作原则（原文三条）

1. 精准戳中高三毕业生、重邮准新生的核心痛点，干货直接给结论，不绕弯子，信息密度高，无废话；
2. 观点必须搭配个人真实经历佐证，增强可信度，**禁止空泛输出**；
3. 电子产品类内容必须客观中立、兼顾优缺点、不盲目种草、不制造焦虑。

## 怎么用（三步）

1. **复制**：打开 `抖音口播文案通用生成提示词（直接复用，换主题即可） (1).md`，整段复制你想用的那一版（通用版 / 优化版）。
2. **换主题**：在粘贴内容的**末尾**补一行——

   ```text
   本次主题：高考完暑假必做的三件事
   ```

   主题越具体越好，建议写成「人群 + 具体动作」，例如"重邮准新生开学前必须搞定的 3 件事"优于"新生攻略"。
3. **丢给 AI**：发给任意对话式大模型，拿到口播初稿后按下面的清单自查一遍再录。

### 拿到初稿后的自查清单（全部来自提示词原文约束）

- [ ] 单句是否都在 **15 字以内**（怼脸口播的节奏前提）？
- [ ] 开头 3 秒是否是强钩子（共鸣问句／痛点直击），而不是"大家好我是…"？
- [ ] 中间每点是否讲清了「是什么 + 有什么用／怎么做」？
- [ ] 是否至少融入了**一条真实经历**佐证，而不是纯空泛结论？
- [ ] 称呼是否统一为"学弟学妹""大家"，有没有冒出"宝子"？
- [ ] 有没有书面语、鸡汤句、烂俗网络梗？
- [ ] 电子产品类：是否覆盖了对应固定观点，且没有硬推品牌型号？
- [ ] 结尾是否有互动引导（如"有问题评论区说，学长挨个回"）？
- [ ] 整体有没有制造焦虑、夸大效果、说教味？

## 使用注意事项

1. **人设是账号专属的**。提示词里的"重庆邮电大学大一在读学长／账号「绿色的氢原子」"以及全部经历，都属于特定账号。**直接照搬会导致文案与你的真实身份不符**，请先把「人设」和「亲身经历库」两段替换成你自己的。
2. **经历必须真实**。原文反复要求"观点必须搭配个人真实经历佐证"，搬用别人的经历来给自己的视频背书，风险由发布者自负。
3. **行情类数字有时效性**。"今年内存／存储涨价""游戏本普遍涨价"这类判断写死在提示词里，换个时间点发布前请自行核实，避免输出过期结论。
4. **AI 内容标注**。文件本身已注明"部分内容可能由 AI 生成"；如果发布平台或所在学校对 AI 生成内容有明确标注要求，请按要求处理。
5. **知识产权**。仓库内未包含 `LICENSE` 文件，即默认未声明开源许可。转载、二次分发或商用前请先联系作者确认。
6. **提示词不能替你判断合规性**。涉及志愿填报建议、消费推荐等内容时，最终把关仍然是人。

## 效果调优建议

这些是从提示词现有约束出发的调整方向，供按需取用（属于使用建议，不是仓库既有功能）：

- **经历库越具体越出效果**：把"我剪视频赚过钱"换成"我暑假剪游戏视频被博主看中、接到了第一单"这种带场景的句子，AI 引用时才不像模板。
- **主题句给足信息**：一次只给一个主题，写明目标人群和具体动作；想测多个方向就分多次生成，而不是让 AI 一次写五条。
- **约束要能自查**：像"单句不超过 15 字"这种可数、可验证的约束保留住，并把自查清单当验收标准用。
- **电子产品的三条观点当硬约束**：这三条是账号的立场表达，删掉后 AI 很容易写成泛泛的"看需求选择"。
- **建立自己的版本**：参考优化版的分章节写法，把你账号的人设、经历库、固定观点、禁忌各自成段，方便长期迭代；本仓库优化版相对通用版的升级思路就是很好的模板。
- **避免风格漂移**：连续生成多条时，把上一版提示词原样保留，只改末尾的主题句，风格一致性最好。
